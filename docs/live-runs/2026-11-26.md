## Found and fixed during the run

An earlier pass the same night failed the agent tool round trip on OpenAI. All three current OpenAI models refused tools on chat completions: gpt-6-luna and gpt-6.1-terra accepted them only with `reasoning_effort: "none"`, and gpt-6.1-sol refused them at every setting. Crossvet now sends OpenAI tool requests through the Responses API and translates the reply back ([design decision 3](../DESIGN-DECISIONS.md#3-pass-agents-tools-through-translate-only-where-a-vendor-requires-it)). The run above is after the fix.
