## What the live run found and fixed

- **OpenAI refused every call.** Its current models reject `max_tokens` and need `max_completion_tokens`. Crossvet now sends the right field to OpenAI and converts it in requests chat apps pass through; other OpenAI-style servers keep `max_tokens`. Regression test: `test_openai_gets_max_completion_tokens_and_passthrough_converts`.
- **A review cut off at the output limit read as broken JSON.** It now says so and names the setting to raise. Regression test: `test_a_cut_off_review_says_so`.
- **Compare results named their cost `cost`; every other tool says `cost_usd`.** They now carry both.
- **Langfuse removed its old trace and score endpoints on 2026-11-16.** Crossvet's recording and `crossvet chat sync` already use the current APIs; the live test checks them through `/api/public/v2/observations` and `/api/public/v3/scores`.
- **A wrong tally of the six searches** (Kelley Blue Book in all six, Sarasota Ford in five) was in the first draft of these prompts. It was recounted result by result and corrected before this run.
