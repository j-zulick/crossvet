## Found by the live runs and fixed before release

- "What is its ZIP code?" was classed as program code (the word "code"). Phrases like ZIP, postal, promo and discount code no longer count.
- A short fact followed by one short question ("… FL 34236. What is its ZIP code? Number only.") was classed as general. It now counts as a quick task.

- `compare` sends its calls in parallel. Two threads running the same query on the log's one connection could fail ("bad parameter or other API misuse") or get no row back, because sqlite3 reuses one prepared statement for the same SQL. Every statement now runs and is read under one lock. The same race could hit the server's thread pool; a test now runs eight threads at once against both files.
- A `Crossvet` given its own log file kept its lab file next to the default log instead. It now sits next to the log in use.

All are covered by unit tests (`tests/unit/test_routing.py`, `tests/unit/test_lab_tools.py`). The last two were found by live runs later the same morning and fixed in this release's code before it was published; this page is the run of the final code.
