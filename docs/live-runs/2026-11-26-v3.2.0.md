## Found by the live runs and fixed before release

- The judge graded the mileage question against the *summary* rubric, because "Answer in one sentence" made the question count as a summary. A length limit no longer does; the question is now a quick task and is graded as one.
- An earlier run of this release failed once in `compare` with an error from SQLite under parallel calls. That was the thread-safety bug fixed in 3.0.0's code ([3.0.0 run](2026-11-26-v3.0.0.md)).
