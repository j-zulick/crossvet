# Crossvet v1.1.0

The chat benchmark, run live: which models do each kind of task, and what they cost.

```bash
uv tool install "crossvet[langfuse] @ git+https://github.com/j-zulick/crossvet@v1.1.0"
crossvet chat start
```

## The 2026-11-25 benchmark

Six models answered all 28 cases (12 standard, 16 hard: traps, strict formats, code edge cases and a document of nearly 12,000 words). Code answers were run in a separate process and checked. 168 calls, none failed, $0.48 in all. Every case is a used-car dealer task from Sarasota, Florida. Full page, with each row's score, cost and the start of the answer: [docs/benchmarks/2026-11-25/](https://github.com/j-zulick/crossvet/blob/v1.1.0/docs/benchmarks/2026-11-25/README.md).

- **Cheap models handled the hard work in these cases.** gpt-6-luna and claude-haiku-5-5 scored 1.00 on code, reasoning, quick questions and the long document, at a fraction of a cent. Every model found the recount buried in the long checklist. The strong slot is a choice for harder work than these cases test.
- **The misses were format misses.** Summaries went over 40 words (gpt-6-luna, gpt-6.1-terra, claude-sonnet-5-5). Subject lines ran to 9 words with a limit of 8 (claude-haiku-5-5, gpt-6.1-terra, claude-sonnet-5-5). claude-opus-5-5 added commentary after its JSON twice, which Crossvet's own JSON check also rejects, and wrote a third sentence in a two-sentence reply.
- **Best value per slot**, from the run: quick: gpt-6-luna, then claude-haiku-5-5. Balanced (writing): gpt-6-luna, then gpt-6.1-sol. `crossvet chat bench --apply` writes this order into your own settings; the example settings keep the starting slots, because 28 small cases are not enough to move code and analysis to the cheapest model for everyone.

## Fixed (found by the benchmark)

The first pass scored some right answers as wrong. Before trusting the table, each miss was checked against its answer:

- `corrected-listing`: all six models wrote `"model": "2016 Nissan Rogue"`, a fair reading of a prompt with no year or make key. The case now asks for year, make and model separately.
- `directory-dealers`: names with a typographic apostrophe (Scotti’s) did not match the key (Scotti's). Quote style is now ignored.
- `gold-certified`: "under six years old" lost a third of the score for not writing the digit. Either spelling now counts.

Benchmark rows now keep the first 600 characters of each answer, which is how these were found.
