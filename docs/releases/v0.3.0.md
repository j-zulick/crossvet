# Crossvet v0.3.0

Long research runs can now pause for a person, survive restarts and be traced end to end.

## Highlights

- **Human approval step.** With `REQUIRE_APPROVAL=true`, the graph pauses after research and before the final report. In the web UI you can approve, edit (add instructions such as focus, length or audience for the report), or reject without spending more on the report; the pause uses LangGraph's `interrupt` and the Agent Chat UI's standard approval format.
- **Durable CLI.** `crossvet run "question"`, `crossvet resume --thread ID` and `crossvet status --thread ID`. Every step is checkpointed to SQLite (`.crossvet/checkpoints.sqlite`) or, with `DATABASE_URL`, to Postgres, so a crashed or interrupted run continues from its last checkpoint. `--auto-approve` and `--out report.md` are available on `run` and `resume`.
- **Langfuse tracing.** Set `LANGFUSE_PUBLIC_KEY` and `LANGFUSE_SECRET_KEY` (and `LANGFUSE_BASE_URL` for a self-hosted instance) to trace runs in Langfuse.

## Configuration

```
REQUIRE_APPROVAL=false
# CROSSVET_CHECKPOINTS=.crossvet/checkpoints.sqlite
# DATABASE_URL=postgresql://...      (uv sync --extra postgres)
LANGFUSE_PUBLIC_KEY=
LANGFUSE_SECRET_KEY=
```
