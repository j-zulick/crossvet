# Crossvet v0.3.0

A light install for the chat.

## Changed
- **The base install is the chat, the scanner and the demo**: three dependencies (httpx, mcp, python-dotenv), about 30 packages, about a second to install on a fresh machine with a fast connection (measured Nov 24, 2026; uv, Python 3.13).
- **Extras:** `research` (research, review, benchmarks, comparisons, the research MCP tools), `langfuse` (chat recording in Langfuse), `all` (both). For everything: `uv tool install "crossvet[all] @ git+https://github.com/j-zulick/crossvet@v0.3.0"`.
- Commands that need research tell you what to install when the extra is missing. `crossvet chat doctor` says when Langfuse keys are set but the `langfuse` package is not installed.
- CI checks the light install on every pull request, and a weekly job runs the tests on the newest version of every dependency (design decision 36).

## Upgrading
If you use research, review or the benchmarks, reinstall with `crossvet[research]` or `crossvet[all]`. From a clone: `uv sync --extra research`.
