# Crossvet v0.2.0

One step from your keys to chatting in Hermes or Cursor, and answers that appear as they are written.

## Added
- **`crossvet chat start`**: writes `crossvet-chat.toml` if there is none, checks that your keys can call a model in quick, balanced or strong, prints the settings to paste into Hermes (base URL, model, API key) and the MCP entry for Cursor with your folder filled in, then serves. `--no-serve` prints the settings only; `--port` changes the port.
- **Streaming**: with `"stream": true`, the server sends each piece of text as it arrives from OpenAI-style providers (OpenRouter, OpenAI, Google, xAI, local servers) and Anthropic, and closes with the model, usage, cost and route. `crossvet chat` and `crossvet chat ask` print answers as they arrive too.
- Hermes and Cursor setup in `docs/CHAT.md`.

## Changed
- A model that fails before sending any text is skipped for the next model, as before. Once text has been sent, a later problem is recorded and no other model is tried; the Jev answer check is not run on streamed answers (design decision 35).

## Limits
- Not yet checked against live Hermes and Cursor installs or live providers; the streaming formats are tested against recorded event shapes.
- Agent requests with tools are answered in one piece.
