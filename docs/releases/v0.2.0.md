# Crossvet v0.2.0

Review findings now have to survive an evidence-grounded critic, and Crossvet's models are available to other coding tools over MCP.

## Highlights

- **Evidence-grounded critic.** Every review finding is checked by a model other than the one that raised it. The critic answers `AGREE`, `DISAGREE_EVIDENCE` (with a quote that code verifies appears in the research notes) or `DISAGREE_CONCERN`. A disagreement without a verified quote does not remove a finding.
- **Disputed section.** Findings the critic contested with evidence are listed in the report instead of being silently dropped or silently applied.
- **Anti-capitulation guidance** for the critic, matching the reviewer and vote prompts.
- **`crossvet-mcp`.** An MCP server (stdio) with `ask_model` and `compare_models`, so Claude Code, Codex or Cursor can query the same configured models.
- **Run export.** `RUN_EXPORT_PATH` appends each reviewed run as one JSON line: brief, draft and revised report, critiques, critic outcome, ballots, tally and flagged URLs. Useful for evaluations and fine-tuning data.

## Configuration

`REVIEW_CRITIC_ENABLED=true` (default when review is on) · `RUN_EXPORT_PATH=runs/crossvet.jsonl`
