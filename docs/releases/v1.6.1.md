# Crossvet v1.6.1

Newer models measured, cheaper defaults, a shorter README.

## What's new
- **Cheaper defaults, measured.** A second benchmark run added GPT-6 Luna, GPT-6.1 Terra and Claude Opus 5.5. GPT-6 Luna matched the top score in compression, report writing and revision at the lowest cost of any model, so it is now the default for summarization, compression and the report. It is weak at planning and search, so research and orchestration stay on GPT-6.1 Sol. Claude Opus 5.5 won no role. Tables, chart and every output: `docs/benchmarks/2026-11-18/`.
- **Incomplete reports flagged in both editions.** The Deep Agents edition now marks a report cut off by an output limit or a provider content filter, as the LangGraph edition does since 1.6.0.
- **A shorter README.** Feature details moved to `docs/FEATURES.md`, design principles to `docs/DESIGN-PRINCIPLES.md`.
- **Contributor basics:** `CONTRIBUTING.md`, issue and pull request templates, and a Dependabot fix.

## Upgrading
Nothing to change. If your `.env` sets `SUMMARIZATION_MODEL`, `COMPRESSION_MODEL` or `FINAL_REPORT_MODEL`, your values still win. `uv run crossvet-bench apply --preset best-value` writes the measured picks for the models your keys can call.
