# Crossvet v1.1.1

Repository presentation only; how Crossvet routes, checks and records requests is unchanged from [v1.1.0](v1.1.0.md).

```bash
uv tool install "crossvet[langfuse] @ git+https://github.com/j-zulick/crossvet@v1.1.1"
crossvet chat start
```

- The README shows how a request is routed as a diagram: kind and difficulty, slot and model, the spend and account guard, the answer check with escalation, and the record your ratings tune.
- Release, CodeQL, Python and license badges.
- `CODE_OF_CONDUCT.md`, so the repository meets every item of GitHub's community profile.
