# Crossvet v1.0.0

Everything on the roadmap, packaged to run with one command.

## What Crossvet does

Deep research whose reports are checked by models from several AI vendors before you read them: independent critiques, an evidence-grounded critic, optional deliberation with a sycophancy guard, anonymized voting, a deterministic citation check and revision by a model outside the panel. Two research engines (LangGraph and Deep Agents), any hosted or self-hosted model, and search through Tavily or your own research gateway.

## New in 1.0

- **One command.** `docker compose up --build` starts the API with both editions and the web UI, bound to localhost. Keys stay in `.env` and are never baked into an image; the API runs as a non-root user.
- **Supply-chain checks in CI.** Docker builds with a smoke test of both graphs, gitleaks over full history, an SPDX SBOM, and CodeQL for Python and TypeScript.
- **Documentation.** Architecture, design decisions with their trade-offs, and an evaluation protocol. Results go in `docs/EVALS.md` only from real runs.
