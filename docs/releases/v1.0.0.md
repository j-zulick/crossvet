# Crossvet v1.0.0

One chat that controls Claude, ChatGPT and other models. Keep using Hermes, Cursor or any chat app: Crossvet sends each request to a model suited to it and shows which model answered, why, and what it cost.

```bash
uv tool install "crossvet[langfuse] @ git+https://github.com/j-zulick/crossvet@v1.0.0"
crossvet chat start
```

## Real use, tested live

The 2026-11-25 run made real API calls through this release's own code: all 12 checks passed with OpenAI and Anthropic, for an estimated $0.08. Every task came from used-car dealer work in Sarasota, Florida. Full table, with every model, route and cost: [docs/live-runs/2026-11-25.md](https://github.com/j-zulick/crossvet/blob/v1.0.0/docs/live-runs/2026-11-25.md).

- A parsing function for a listing title such as "2021 Toyota Tacoma SR5 - 34,210 mi - $31,995" was classified as code and went to the strong slot (claude-opus-5-5, $0.041). A one-line mileage question went to the quick slot (gpt-6-luna, under $0.0001). A reply to a shopper went to balanced (claude-sonnet-5-5).
- Through the server, the way Hermes calls it: a plain answer, a streamed answer, and `/why`.
- A bar chart of how many searches each site appeared in, sent as an image, went to the vision slot and was read correctly.
- A per-call spend cap stopped a request before any model was called. With an invalid OpenAI key, Anthropic answered and OpenAI was not called again.
- gpt-6-luna and claude-haiku-5-5 answered side by side, and claude-opus-5-5 challenged a claim written by an OpenAI model.
- A rated answer reached Langfuse with its score. The MCP server, started the way Cursor starts it, listed its 13 tools and answered.

The run found one serious bug: OpenAI's current models refuse `max_tokens`, so every OpenAI call failed. This release sends `max_completion_tokens` to OpenAI.

## What's in it

- **Connections:** an OpenAI-compatible server for Hermes and any chat app (model `auto`), MCP tools for Cursor, Claude Code and Codex, and a terminal chat. `crossvet chat start` prints the settings to paste.
- **Routing in code:** each request's kind of task, its difficulty, and what it carries (images, audio, PDFs, code) pick a slot and a model, and `/why` shows the reason. `/model NAME` picks a model yourself, `/retry stronger` moves up a step, goals choose best, cheapest or fastest, and private requests stay on a local model.
- **The guard:** the next model is tried only after a failed answer check. Daily and per-call spend caps apply. A provider that refuses your key or reports billing trouble isn't called again.
- **Your record:** every turn and rating is saved locally and copied to Langfuse. Ratings propose routing changes that only you accept, and a learned router has to beat the rules before you turn it on.

Not run live yet: the Hermes and Cursor apps themselves, Google, xAI, OpenRouter, Jev and local models, and the chat benchmark. The routing table is the starting table written from judgment on 2026-11-23, labelled as such.

## Changed from v0.1.1

Crossvet is now only the chat. The research pipeline, cross-vendor report review, the `crossvet scan` command, the role benchmark, the web UI and the LangGraph server were removed; they remain in v0.1.1's history. The base install has three dependencies. Every change: [CHANGELOG.md](https://github.com/j-zulick/crossvet/blob/v1.0.0/CHANGELOG.md).
