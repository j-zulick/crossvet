# Crossvet v0.7.0

The chat on your own server: Cursor's chat, the ChatGPT and claude.ai apps, your phone.

## Added
- **Sign-in for the MCP server:** `crossvet chat mcp --http --host 0.0.0.0 --public-url https://your-domain`. Apps register themselves and send you to a sign-in page; you sign in with `CROSSVET_CHAT_TOKEN` (at least 16 characters). OAuth with PKCE from the MCP SDK; codes work once; access tokens last 1 hour; refresh tokens last 30 days and are replaced on every use; only hashes are stored; tokens are accepted only for this server; other host names are refused; five wrong passphrases in 15 minutes lock sign-in.
- **`deploy/chat/`:** Docker Compose with the API, the MCP server and Caddy for HTTPS, plus a setup guide with where to connect Cursor, Hermes, claude.ai and ChatGPT.
- `CROSSVET_CHAT_PUBLIC_URL` and `CROSSVET_CHAT_OAUTH_DB`.
- CI builds the chat image and checks that the API starts and requires its token.
- Design decision 40.

## Limits
Not yet run on a live server or connected to the ChatGPT and claude.ai apps. The full sign-in flow is tested against the real MCP server app in-process, and both servers were started from the image's install with the sign-in metadata checked.
