# Crossvet 2.0.1: agents' tool calls, hardened

Agents such as Hermes send tools on every request. 2.0.0 made them work with Claude and GPT; 2.0.1 makes that path robust.

- **Streamed tool calls.** Requests with tools stream when the app streams, for every provider, so an agent sees the answer as it is written rather than waiting for the whole reply.
- **OpenAI reasoning kept across tool steps.** OpenAI's current models take tools only through the Responses API. Crossvet now keeps the model's encrypted reasoning (with `store: false`) and sends it back with the tool results, so the model continues its train of thought instead of starting over.
- **Nothing dropped silently.** A field a vendor's API has no place for is listed under `crossvet.dropped`; several answers per request (`n` above 1) is refused with a clear error.
- **Fuller translation:** developer messages, assistant text with tool calls, tool results as parts, refusals, content-filter and length stops, the older `functions` format.
- **Tested against real replies:** offline tests built from replies recorded from OpenAI's and Anthropic's APIs.
