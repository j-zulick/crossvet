# Crossvet v1.5.0

Research that knows its field, answers follow-ups from its own evidence, and runs from your code.

## New in 1.5

- **Context and domain packs.** Say who is asking and why with `RESEARCH_CONTEXT`, and pick `CONTEXT_PACK=seo`, `marketing` or `real-estate` for that field's evidence rules: which sources count as primary, which claims go stale, what reviewers should check. Both go into the research brief, so research, critique, deliberation and revision all work to them.
- **Follow-up questions.** `crossvet ask --thread ID "question"` answers about a finished run in one model call, from that run's notes only, with the same citation check as the report. If the notes don't cover the question, the answer says so.
- **Python API.** `from open_deep_research.api import run, ask`: run either edition with any setting, then ask follow-ups.

## Upgrading

Nothing changes unless you set `RESEARCH_CONTEXT` or `CONTEXT_PACK`, or use the new command and API.

See `docs/DESIGN-DECISIONS.md` #16.
