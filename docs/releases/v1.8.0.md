# Crossvet v1.8.0

The injection check becomes a tool you can point at any page, and the review becomes a tool you can point at any report.

## What's new
- **`crossvet-scan`.** Checks any page, file or pasted text for text aimed at AI models, and says where it hides: visible text, hidden elements, HTML comments, attributes such as alt text, or meta tags. Invisible Unicode tag text and base64 blobs are decoded first. JSON output and an exit code for CI. The MCP server offers it as `scan_for_injection` for Claude Code, Codex and Cursor, refusing non-public addresses. No model, no API key.
- **`crossvet review`.** Runs the cross-vendor review on a report from any tool or person, against the files or URLs it should rest on: `crossvet review report.md --sources audit.md https://example.com/study`. Also `api.review`.
- **Claims resting only on flagged sources go to *Disputed*.** Code maps each sentence to the sources it cites; when every one was flagged by the injection check, the sentence is listed for a human check.
- **Hardening.** The summarizer's data wrapper carries a random per-call marker.

## Upgrading
Nothing to change. `crossvet-scan` and `crossvet review` are new commands.
