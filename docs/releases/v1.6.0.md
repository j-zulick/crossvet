# Crossvet v1.6.0

Which model for which job, measured.

## New in 1.6

- **Any model in any role.** Every stage and every review role now takes any `provider:model`: OpenAI, Anthropic, Google, most other vendors through one OpenRouter key (official `langchain-openrouter` integration, with the real cost of each call), or a model on your own machine.
- **Orchestration and research split.** `SUPERVISOR_MODEL` plans and delegates; `RESEARCHER_MODEL` searches and reads. Both default to `RESEARCH_MODEL`.
- **`crossvet-bench`.** Tests each role on its own with Crossvet's real prompts, on synthetic cases a model can't answer from memory, and scores it with code: planted errors with an answer key, facts and URLs that must survive, checklists of what a plan must cover. You get a leaderboard per role, a quality-vs-cost chart, and best-quality and best-value picks. `crossvet-bench apply --preset best-value` writes them to `.env`.
- **Checked before you spend.** Setup saves OpenRouter's catalog; the doctor fails a role whose model can't call tools or return typed output; `--dry-run` estimates cost; `--max-usd` caps it.
- **First results.** Four models from two vendors on every role: Claude Haiku 5.5 came within 0.03 of the best score in six of seven roles at 7 to 19 times lower cost; every model caught every planted error. Tables, chart and every output: `docs/benchmarks/2026-11-17/`.
- **Safer revisions.** A revision that stopped at the output limit, or lost most of the draft's sources, no longer replaces the draft; a Claude reviser's thinking blocks no longer leak into the report.
- **Measured defaults.** Stage models move from `gpt-4.1` (retiring January 14, 2027) to the benchmark's picks: `gpt-6.1-sol` for research and orchestration, `gpt-5.4-mini` for summarization, compression and the report. Newer models not yet benchmarked (`gpt-6-luna`, `gpt-6.1-terra`, Claude Opus 5.5) are listed with the command to measure them.
- **Includes v1.5** (context packs, follow-up questions, Python API) and the `crossvet-doctor` command.
- **Clearer repository.** A TL;DR and *Measured so far* section open the README, with what hasn't been measured yet; *Related projects*, *My role and AI assistance* (`docs/CONTRIBUTIONS.md`) and *Release history* sections; `AGENTS.md` for coding agents; upstream's unused legacy code removed.

## Upgrading

Nothing to change. To try it: `uv run crossvet-bench suggest`, then `uv run crossvet-bench run --models … --dry-run`. Method and scoring: `docs/MODEL-SELECTION.md`. Design notes: `docs/DESIGN-DECISIONS.md` #17.
