# Crossvet v1.4.0

A real quote can still be the wrong evidence. Now a decision model checks.

## New in 1.4

- **Support checks with Jev.** With `REVIEW_SUPPORT_CHECKER=jev`, every passage used as evidence is put to Jev, TypeSafe's decision model: does this passage support this claim? Jev answers with a probability.
- **Where it counts.** A low score turns a deliberation position change into an ungrounded one (the finding stays), stops an AGREE from counting as grounded (so the false-consensus guard can step in), blocks a BUILD_ON addition, and drops a blind-pass point.
- **Code stays the first gate.** Evidence must still be a verbatim quote from the notes. If a Jev call fails, that claim falls back to the quote check, and the Review notes say so.
- **Easy to verify.** `uv run crossvet-doctor --jev` asks two questions with known answers. Scores and the Jev version that answered are kept in the export; `crossvet-compare` and Langfuse record `support_checked` and `support_rejected`.

## Upgrading

Off by default. Set `TYPESAFE_API_KEY` and `REVIEW_SUPPORT_CHECKER=jev` (or re-run `crossvet-setup` with the key set). Pin a version with `REVIEW_SUPPORT_MODEL`.

See `docs/DESIGN-DECISIONS.md` #15.
