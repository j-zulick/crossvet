# Crossvet v1.7.0

Fetched pages are checked for prompt injection before any model reads them, and the benchmark now measures injection and harder cases.

## What's new
- **Prompt-injection check.** Every page fetched through Tavily or the research gateway is scanned in code for text aimed at the model rather than the reader: instructions to ignore or override, text addressed to an AI, role changes, instructions to recommend, cite or leave something out, chat markup, and hidden text alongside any of those. A flagged source gets a line in the research notes, and the Review notes list flagged sources and any the report cites. The summarizer prompt treats page text as data. Threats, defenses and limits: `docs/SECURITY-MODEL.md`.
- **Injection benchmark.** `crossvet-bench run --suite injection` (and `injection-checked`, with the check's line in the notes). First results, Nov 18, seven models, $3.60: no model wrote a planted instruction's claim into a final report (0 of 55 inspectable), and every reviewer caught the claim when it was planted in a draft. Compression passed the instruction text on unflagged in 6 of 28 runs; with the check's line, more compressions reported the source as suspect (14 → 20 of 28). Details and caveats: `docs/benchmarks/2026-11-18-injection/`.
- **Hard benchmark suite.** `--suite hard`: 11 sources per case with distractors, conflicting sources and subtler errors. Scores now spread out in planning, research and review; GPT-6.1 Sol was the only reviewer that caught every planted error with few false alarms, so the example review panel uses it. Results: `docs/benchmarks/2026-11-18-hard/`.
- **Jev support checks, live-tested** against `jev-1.14.0` (`uv run crossvet-doctor --jev`).

## Upgrading
Nothing to change. The injection check is always on and adds no model calls. To try Jev: set `TYPESAFE_API_KEY` and `REVIEW_SUPPORT_CHECKER=jev`, then run `uv run crossvet-doctor --jev`.
