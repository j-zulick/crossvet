# Crossvet 3.1.0: another vendor reviews your change

`crossvet review --staged --task "..."` sends your change to a model from a different vendor than the one that wrote it, and shows only the findings that hold up against the diff.

## What's new
- **Findings checked in code.** A finding is kept only when its file is in the diff, its line is a line the diff shows, its quote is on that line word for word, and its severity is one of four. Everything else is dropped and counted, with the reason.
- **Fix in rounds.** `--fix` asks the author model for a patch that `git apply --check` must accept; `--apply --rounds 2` applies it and reviews again. Each review leaves a decision record.
- **From your agents.** The MCP tool `review_diff`, a Claude Code plugin (`/plugin marketplace add j-zulick/crossvet`), and skills for Codex and Hermes.
- **The review benchmark.** Twelve changes to Crossvet's own code with one planted bug each; `crossvet bench --review -m MODEL ...` counts catches in code. The run of 2026-11-26 is published in `docs/benchmarks/`.

## Upgrade
`uv tool install --force "git+https://github.com/j-zulick/crossvet@v3.1.0"`. Nothing else changes.
