# Crossvet v0.1.0

The first release of Crossvet: a deep-research agent whose report is reviewed by models from different vendors before you read it.

## Highlights

- **Cross-vendor review.** After the draft report, reviewers from different vendors critique it in parallel with typed output. Their critiques are anonymized and shuffled, ranked by the panel with a confidence-weighted Borda count, and used by a separate reviser model to produce the final report.
- **Deterministic citation check.** URLs cited in the report are compared against what the research step actually read; anything unmatched is flagged in the Review notes.
- **Review notes.** Each report ends with scores, the peer-voted best critique, dissent, flagged citations and any reviewer that failed.
- **Bias safeguards.** Reviser outside the panel (with a warning when it shares a vendor with a reviewer) and prompts that ask reviewers to hold evidence-based positions. See *Design principles* in the README for the research behind each choice.
- **Any model, including your own.** Hosted providers, OpenRouter, Ollama, and any OpenAI-compatible local server (llama.cpp, LM Studio, MLX, vLLM).
- **Setup checker.** `uv run python -m open_deep_research.doctor` reports missing keys and weak review panels without printing key values.
- **Web UI.** Agent Chat UI in `web/`.

## Upgrading from Open Deep Research

Crossvet is built on LangChain's Open Deep Research (MIT). Review is off by default; set `CROSS_VENDOR_REVIEW_ENABLED=true` and `REVIEW_MODELS` to turn it on. LangGraph 1.2 and LangChain 1.x are required.

## Known limitations

- Review adds one call per reviewer for critique, one per reviewer for ranking, and one revision call.
- The citation check matches URLs only; it does not verify that a cited page supports the claim.
