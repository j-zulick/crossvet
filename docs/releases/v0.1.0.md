# Crossvet v0.1.0

The first release in this repository. Crossvet was designed and built from November 6 to 24, 2026 in a private repository, one tested version at a time; this is the result.

## What's in it
- **Reviewed research reports** (`crossvet research`, `crossvet review`): reviewers from different AI vendors critique a draft in parallel; critiques are anonymized and ranked with a confidence-weighted Borda count; a citation check in code flags URLs the research never read; an independent critic can overrule a finding only with a quote that code finds verbatim in the notes; unresolved findings go to *Disputed*. The Review notes open with a verdict counted in code. Optional deliberation rounds stop by rule, and an optional blind first pass catches omissions.
- **Crossvet chat** (`crossvet chat`): one chat in front of several vendors' models, routed by rules in code, Jev or a hosted router, with the reason shown; turns, costs and ratings kept locally and optionally in Langfuse; a routing table you tune from your ratings and from injection-checked posts; replay of your history through other routers; versioned handoff packets between models and agents with results checked in code; an OpenAI-style server and MCP tools.
- **Prompt-injection check** (`crossvet scan`): every fetched page is checked in code before a model reads it; the same check runs on any page, file, sitemap or URL list with no model and no key.
- **Which model for which job** (`crossvet bench`): each pipeline role scored with answer keys; best-quality or best-value models written to `.env`.
- **Cost and control:** `--estimate` before a run, `--max-usd` spend cap, `--effort` tiers, escalation to a stronger model only after a failed check in code.
- **Durable runs:** every step checkpointed to SQLite or Postgres, with resume and optional human approval; LangGraph and Deep Agents editions share the same review.

## Install
```bash
uv tool install "git+https://github.com/j-zulick/crossvet@v0.1.0"
crossvet demo
```
Or `pip install` the wheel attached to this release. Then `crossvet setup` in the folder you'll work from, and `crossvet doctor`.
