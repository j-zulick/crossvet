# Crossvet v1.11.0

v1.11 makes Crossvet easier to start with and adds controls for how much a run costs. Nothing changes for an existing setup until you use the new flags or settings.

## What's new

### One command, three things to try first
- `crossvet scan`, `crossvet review` and `crossvet research` are the three uses, and `crossvet --help` opens with them.
- Every other tool is a subcommand too: `try`, `setup`, `doctor`, `bench`, `compare`, `dataset` and `mcp`. The separate `crossvet-*` commands still work.
- The README starts with a Start here section, and a sample scan report is in `docs/samples/`.

### Five settings that matter, and the rest marked advanced
- `.env.example` and `docs/SETTINGS.md` put provider keys, the search source, the review panel, the reviser and the research model first.
- Everything else is under Advanced.

### Effort tiers
- `--effort quick|standard|deep` on `crossvet research` and `crossvet try`, or `EFFORT` in `.env`.
- `quick` runs less research and a two-reviewer panel. `deep` runs more research rounds, two deliberation rounds and the blind pass.
- `--effort auto` picks the tier from the question's text, in code, and says why. Unclear questions get `standard`.
- A setting you set yourself always wins over the tier.

### Escalation after a failed check
- `ESCALATION_MODEL` names a stronger model that is used only when a stage's own model fails in a way code can see: an error or unparseable structured output after the retries, or a report that is cut off.
- Review roles, the supervisor and the researchers are never escalated.
- Each escalation is listed in the Review notes.

### Spend cap
- `--max-usd` or `MAX_RUN_USD` refuses the next model call once the counted spend reaches the cap. The command exits with code 3.
- Calls with no known price can't be counted; the summary says how many there were.

### Releases publish themselves
- When a new version lands on `main`, a workflow creates the GitHub release from `docs/releases/` and uploads to PyPI.

## Not measured yet
The tier values and the question rules are starting points. No run has compared the tiers on cost and on review findings. Design decision 26 lists the costs.

## Upgrading
- Nothing to change. Without `EFFORT`, `ESCALATION_MODEL` or `MAX_RUN_USD`, runs behave as in v1.10.
- `.env.example` is reordered; your `.env` is not touched.
