# Crossvet v0.6.0

A second research engine: LangChain's Deep Agents, with the same cross-vendor review on top.

## Highlights

- **Deep Agents edition** (graph `deep_agent`). Instead of the fixed research graph, a Deep Agent plans its work with a to-do list, sends focused sub-questions to a researcher sub-agent and writes the report to its virtual filesystem.
- **Grounding the agent can't skip.** A callback records every search result returned to the agent or any sub-agent. Those results, not the agent's own summary, are what the citation check, the critic and deliberation verify against.
- **Same review, same settings.** All `REVIEW_*` options apply unchanged, and the run export and Review notes look the same.
- **Head to head.** `crossvet-compare --setups examples/compare/editions.toml` runs both editions on the same questions and models.

## Notes

- Works with Tavily or a model's built-in search (`SEARCH_API=openai` / `anthropic`): built-in search sources are read from every model reply, including the sub-agents'.
- `RESEARCH_MODEL` drives the agent and its sub-agent.
