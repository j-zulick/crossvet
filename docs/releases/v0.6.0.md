# Crossvet v0.6.0

Backups, restores, retention and two new limits.

## Added
- `crossvet chat backup [PATH]`: a consistent copy of the chat store, safe while the server runs, checked before it is reported.
- `crossvet chat restore PATH --yes`: checks the backup and saves the current store first.
- `crossvet chat prune --older-than DAYS --yes`: keeps the last N days of turns and their ratings, and every note, the routing table, evidence and handoffs; the store keeps its id, so Langfuse trace ids still match; a backup is saved first.
- `[limits] timeout_seconds` (120) for one model call and `[limits] max_request_bytes` (2,000,000) for the server, which answers larger requests with HTTP 413.
- Design decision 39.

## Note
Stop `crossvet chat serve`, `start` and any MCP server before `restore` or `prune`.
