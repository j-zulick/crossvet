# Crossvet 2.0.0: pick any model

**One chat, any model, and you choose it.** Crossvet 2.0 is smaller and simpler than 1.x: name the model from Hermes, Claude Code, Codex, Cursor or a terminal, and that model answers. Crossvet no longer chooses, rates or compares models.

## What you can do
- **Name any model** as `provider:model` or a short name (`opus`, `sonnet`, `sol`, `luna`). A request that names none goes to your one `default_model`.
- **Switch mid-conversation** with `/model NAME` in any app; `/models` lists them and `/cost` shows spend for this conversation and today.
- **Use the app's model menu:** Hermes and other OpenAI-style apps read your models from `/v1/models`.
- **Keep your agent's tools.** Tool calls pass through to Claude (through Anthropic's OpenAI-compatible endpoint) and to GPT (through OpenAI's Responses API, because OpenAI's current models refuse tools on chat completions).
- **One-line installs:** `claude mcp add --scope user crossvet -- crossvet mcp`, `codex mcp add crossvet -- crossvet mcp`; `crossvet start` prints the Hermes and Cursor settings.
- **Spend caps in code:** a daily cap and a per-call worst-case cap stop a call before it is made; a provider that rejects your key is not called again.

## Tested live
13 checks passed with OpenAI and Anthropic keys for $0.023 on 2026-11-26: six models answered by name; the server switched vendors mid-conversation and streamed; tool calls round-tripped through Claude Sonnet, GPT-6.1 Sol and GPT-6 Luna; the caps and the rejected-key guard held; and the MCP server answered over stdio. [docs/live-runs/2026-11-26.md](https://github.com/j-zulick/crossvet/blob/v2.0.0/docs/live-runs/2026-11-26.md)

## Breaking changes
Routing, slots, goals, ratings, Langfuse, the benchmark and 18 other commands are removed; 10 of 13 MCP tools are removed; settings files and three environment variables changed. Your log of past turns opens unchanged, and the 1.x spellings of the kept commands still work. [Moving from 1.x](https://github.com/j-zulick/crossvet/blob/v2.0.0/docs/MIGRATING.md)

## Install
```bash
uv tool install "git+https://github.com/j-zulick/crossvet@v2.0.0"
crossvet start
```
