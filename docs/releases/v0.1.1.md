# Crossvet v0.1.1

Fixes fresh installs of v0.1.0, updates dependencies, and cuts update pull requests to one per kind a month.

## Fixed
- **Fresh installs work again.** `uv tool install` and `pip install` from GitHub do not read `uv.lock`, so they picked up `mcp` 2.x, which renamed APIs that Crossvet's MCP servers and LangChain's MCP adapters import: `crossvet mcp`, `crossvet chat mcp` and research runs failed to start. `mcp` is now capped below 2, and a test keeps the cap. With the cap, the 640 offline tests pass on a fresh install with every other dependency at its newest version (checked Nov 24, 2026).

## Changed
- GitHub Actions: `astral-sh/setup-uv` 7, `pnpm/action-setup` 6, `actions/upload-artifact` 7, `actions/download-artifact` 8.
- Python: `requests` 2.34.2, `tavily-python` 0.8.5, `supabase` 2.34.1, `langchain-openrouter` 0.3.0.
- Web UI: `@langchain/core` 1.5.0, `tailwind-merge` 3.7.1, `postcss` 8.5.33, `eslint-plugin-react-refresh` 0.5.8.
- Dependabot groups all updates of one kind (Python, web, GitHub Actions) into one monthly pull request.

## Checked
Each update passed CI on its own pull request; together they pass the offline tests, the lock check and a frozen web install.
