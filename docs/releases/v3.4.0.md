# Crossvet 3.4.0: the daily driver

Crossvet is meant to be the one endpoint every chat app on your computer talks to. 3.4 makes it run that way.

## What's new
- **`crossvet service install`.** The server starts at login and restarts if it stops: launchd on macOS, systemd on Linux, listening on 127.0.0.1. `--weekly` adds a Monday job that judges a sample of the week's answers, applies score routes if you allowed it, and saves the weekly report. `crossvet service status` checks it.
- **On a server.** A `Dockerfile` and `compose.yaml` for a droplet, a home server or a Komodo stack. The container refuses to listen beyond localhost without a 16+ character token, and the compose file publishes the port on 127.0.0.1 only. See [DEPLOY.md](../DEPLOY.md).

## Upgrade
`uv tool install --force "git+https://github.com/j-zulick/crossvet@v3.4.0"`, then `crossvet service install` if you want it in the background.
