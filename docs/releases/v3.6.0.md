# Crossvet 3.6.0: repeated benchmark runs

## What's new
- **`crossvet bench --review --repeat N`.** Each change is reviewed N times, and the results show which bugs a reviewer catches every run and which only sometimes.
- **Three runs of the hard set, six reviewers ($0.64):** no false alarms in 108 reviews of clean changes; Claude Haiku and GPT-6.1 Terra caught all 12 bugs in every run, Claude Opus 4 of 12 (its misses were all findings dropped for an empty severity). [Results](../benchmarks/2026-11-27-review-hard-repeat/README.md).
- **CI:** gitleaks-action 3.
