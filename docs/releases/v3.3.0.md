# Crossvet 3.3.0: route from scores

When the judge from 3.2 has scored enough of your answers, `auto` can stop guessing from text rules and route from evidence: the cheapest model that your own judged answers show is good enough for each kind of task.

## What's new
- **`[router] use = "scores"`.** Among models with enough judged answers for the kind of task, the cheapest within a margin of the best cautious score goes first. About 5% of requests try the second choice so other models keep being scored. Too few scores, or a judge that disagrees with your ratings, and the rules decide; `/why` says which.
- **Proposals and automatic changes.** `crossvet tune scores` turns the leaderboard into proposals with evidence. With `[router] auto_tune = true`, `crossvet tune auto` accepts at most one per kind a week and rolls a change back when the new model scores clearly worse.
- **The weekly report.** `crossvet report --week --json` gives spend, the saving against always using the strongest model, the judged score against the week before, and route changes. An n8n workflow and a Windmill script run the weekly steps.

## Upgrade
`uv tool install --force "git+https://github.com/j-zulick/crossvet@v3.3.0"`. Routing changes only if you set `use = "scores"`.
