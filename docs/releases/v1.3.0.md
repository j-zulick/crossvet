# Crossvet v1.3.0

Your models, your panel.

## New in 1.3

- **Pick any model.** `crossvet-setup --panel … --reviser …` takes any `provider:model` your keys can call, and `--list-models openrouter --filter grok` shows every id a provider offers. Setup checks the choice (unknown names, a one-vendor panel, a reviser sharing a vendor) instead of overwriting it, and keeps an existing panel on later runs (`--auto` re-picks).
- **Wider coverage.** Through one OpenRouter key the automatic pick now also considers Z.ai (GLM) and Moonshot (Kimi), next to xAI, DeepSeek, Qwen, Mistral and Meta. `OPENROUTER_PROVIDER_ORDER`, `OPENROUTER_ALLOW_FALLBACKS` and `OPENROUTER_DATA_COLLECTION` control which hosts serve those models.
- **Resilience.** `REVIEW_FALLBACK_MODELS` replaces a failed reviewer with a spare, preferring a new vendor, and says so in the Review notes. `REVIEW_CALL_TIMEOUT` stops one hung call from holding up a run.
- **`crossvet sessions`** lists saved runs, newest first.
- **Langfuse scores on every CLI run**, with the same names as `crossvet-compare`, so everyday runs and comparison runs chart together.

## Upgrading

Re-running `crossvet-setup` no longer replaces a panel you set; use `--auto` for the old behaviour.
