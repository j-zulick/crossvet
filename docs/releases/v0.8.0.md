# Crossvet v0.8.0

Research can now run on search infrastructure you operate instead of a paid search API.

## Highlights

- **`SEARCH_API=gateway`.** The researcher calls a research gateway over MCP (Streamable HTTP, bearer token). Discovery uses SearXNG metasearch; pages are read with plain HTTP first, then Firecrawl, then a headless browser.
- **Provenance per source.** Each result records the engine that found it, the reader that fetched it and an honest status (`ok`, `partial`, `blocked`, `failed`). Nothing is dropped silently.
- **Contract-tested.** Tests mirror the gateway's `search_and_read` reply, including failed reads and sources skipped for time, and each source keeps its extractor and outcome for provenance.
- **Resilient adapter.** Tolerates schema differences between gateway releases and isolates failures per query, so one bad query does not end the research step.
- **Combined search.** `SEARCH_ALSO=openai` (or `anthropic`) gives researchers the model's built-in web search next to the gateway, so research continues if one source comes back empty.
- **Setup checker** reports a missing `RESEARCH_GATEWAY_URL` or `RESEARCH_GATEWAY_TOKEN`.

## Configuration

```
SEARCH_API=gateway
RESEARCH_GATEWAY_URL=https://your-gateway.example.com/research/mcp
RESEARCH_GATEWAY_TOKEN=...
SEARCH_ALSO=openai            # optional
```

Tavily and model-native search still work as before.
