# Crossvet v0.4.0

Compare model setups on the same questions, so choosing a local or hosted model for each role is based on measurements instead of impressions.

## Highlights

- **`crossvet-compare`.** Runs every question under every named setup, with optional repeats. A setup is any combination of Crossvet settings, so you can swap the report writer for a model on your own machine, try a different reviewer panel, or turn the critic off.
- **What gets recorded.** Finished or failed, latency, input and output tokens per model, URLs cited, URLs the citation check flagged, reviewer scores, critic drops and disputes, and failed reviewers.
- **Outputs.** `results.jsonl` (one line per run), `summary.md` and `summary.csv` (one row per setup) and every report under `reports/` for side-by-side reading.
- **Safe to leave running.** A failed run is recorded and the comparison moves on; runs never pause for approval.

## Try it

```
uv run crossvet-compare --setups examples/compare/setups.toml --questions examples/compare/questions.txt --repeats 2
```

## Limits

Reviewer scores come from each setup's own panel, so compare them across setups only when the panels match. The metrics are signals for where to look, not a quality verdict: read the reports.
