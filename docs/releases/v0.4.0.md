# Crossvet v0.4.0

Ratings you add in Langfuse count, and a weekly report.

## Added
- **`crossvet chat sync`**: scores people added in Langfuse's interface (named `user-feedback` by default) are saved as ratings on the answers they belong to, so `crossvet chat tune` counts them. Values become good or bad by a rule in code (0–1 numbers, true/false, good/bad labels); Crossvet's own scores are skipped and each score is saved once. `crossvet chat tune --sync` syncs first.
- **`crossvet chat report`**: for the last 7 days (or `--days N`): answers and cost, cost per model, ratings per kind of task, and proposed table changes. `--out` writes it to a file; `--langfuse` posts it to Langfuse as a trace named `crossvet-weekly-report`.
- Design decision 37.

## Limits
Tested against a stand-in built from the Langfuse SDK's score types (SDK 5.2); not yet run against a live Langfuse project.
