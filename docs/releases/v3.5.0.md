# Crossvet 3.5.0: a harder review benchmark

## What's new
- **`crossvet bench --review --set hard`.** Twelve subtler bugs planted in Crossvet's real code (a ladder cut one model short, a lock released before the rows are read, a week written in seconds) and six clean changes. A blocker or major finding on a clean change counts as a false alarm.
- **First run, six reviewers:** no false alarms; Claude Haiku, Claude Sonnet and GPT-6.1 Terra caught all twelve (Haiku for $0.0045). Most misses were findings dropped for a missing severity or a wrong file, not bugs left unseen. [Results](../benchmarks/2026-11-26-review-hard/README.md).
- **Model switching, shown.** The README has a real `crossvet chat` session moving from Claude Haiku to GPT-6.1 Sol to `auto` in one conversation.
