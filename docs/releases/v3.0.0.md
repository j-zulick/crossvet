# Crossvet 3.0.0: pick the model, or let Crossvet choose and show why

One chat, any model, from Hermes, Claude Code, Codex, Cursor or a terminal. Name a model and that model answers, exactly as before. Name `auto` and Crossvet chooses one from the kind of task, tells you why, and tries the next model when an answer fails a check.

## What's new
- **`auto`, slots and goals.** `auto` picks a slot from the kind of task (code and reasoning go to `strong`, quick lookups to `quick`, reviews to another vendor); `crossvet/strong`, `crossvet/cheapest`, `crossvet/fastest` let you steer. `/why` and `crossvet route` explain every choice.
- **Escalation, narrowly.** An error, an empty answer or invalid JSON moves to the next model before anything is shown. A model you named is never switched.
- **Private stays private.** Under `auto`, a request with a key, a card or ID number, or marked confidential only goes to a model on your machine, or is refused.
- **Ratings and tuning.** `/good` and `/bad` from any chat; `crossvet tune` proposes better routes from them, and changes nothing until you accept.
- **Several vendors at once.** `compare`, `challenge` (another vendor's verdict, read in code) and `replay` (past questions on another model, judged blind).
- **The Sarasota benchmark**, notes shared by every app, handoffs to Claude Code and Codex, reports, a dashboard page, export, Langfuse sync, backup and restore.

## Upgrade
`uv tool install --force "git+https://github.com/j-zulick/crossvet@v3.0.0"`. Nothing breaks for 2.x users; see [MIGRATING.md](../MIGRATING.md).
