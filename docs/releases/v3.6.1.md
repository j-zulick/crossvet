# Crossvet 3.6.1: Langfuse sync on Langfuse v4

## Fixed
- **`crossvet sync` works again.** Langfuse Cloud turned off its old trace ingestion on 2026-11-16, so sync failed with HTTP 410. Answers now go to Langfuse over OpenTelemetry, as generations with model, tokens and cost; ratings and judge scores still attach to them.
- **No more overwritten ratings.** Score ids now include a per-install id, so two Crossvet installs sharing a Langfuse project no longer overwrite each other's ratings.

## Tested live
A Claude Haiku answer and its rating showed up in Langfuse Cloud within 10 seconds, with the right model, tokens and cost.

## Upgrade
`uv tool install --force "git+https://github.com/j-zulick/crossvet@v3.6.1"`
