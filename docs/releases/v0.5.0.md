# Crossvet v0.5.0

More posts in, less noise out.

## Added
- `crossvet chat routes import FOLDER`: every `.txt`, `.md` and `.html` file in a folder (up to 500), each through the injection check, the extraction and the verbatim-quote check as before.
- `--urls FILE`: a reading list, one URL or file path per line.
- After each post, every kept claim with what accepting it would change, and whether it repeats or contradicts an earlier post.
- `routes evidence` shows a claim made by several posts once, with the count, and marks claims another post contradicts.
- Accepting or rejecting a claim decides its repeats from other posts too, with one change to the table; `--one` decides only that claim.
- Design decision 38.
