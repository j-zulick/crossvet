# Code of conduct

Crossvet follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive in issues, pull requests and reviews. Critique code and ideas, not people. Harassment, personal attacks and sharing someone else's private information are not accepted.

## Reporting

Report unacceptable behavior privately to the maintainer through GitHub ([@j-zulick](https://github.com/j-zulick)), or with the **Report content** option on the comment or issue. Reports are read, handled confidentially, and answered.

## Enforcement

The maintainer may edit or remove comments, close issues and pull requests, and block accounts that break this code, as the Contributor Covenant's enforcement guidelines describe.
